General

How this bridge presents itself.

Shown in the page header and in Telegram status messages.
Put in front of every message you send into the mesh. Leave empty for none.
Anyone who can open this page sees the map and public messages without logging in. Private messages and sending always need the password.
Empty = zoom to the nodes that have been heard.

Telegram

Mesh messages are posted to one Telegram chat; people in that chat can reply into the mesh.

Create a bot by talking to @BotFather in Telegram (/newbot) and paste the token it gives you.
Finding the chat id: save with the token filled in, then send /id to your bot (or add the bot to a group and send /id there). The chat appears below — click “Use”.
Your private chat with the bot, or a group (group ids start with −).
Telegram user ids allowed to send into the mesh, comma separated.

Meshtastic

A Meshtastic radio reached over Wi-Fi/Ethernet (TCP port 4403) or a USB cable.

Turn on Wi-Fi in the radio's Network settings; the bridge connects on port 4403.
Which channel is bridged as “public”. 0 is the primary channel (LongFast).

MeshCore

A MeshCore companion radio (USB firmware, or Wi-Fi/TCP firmware). Repeater firmware cannot be used.

A USB port can only be used by one program at a time — close the MeshCore web app / other tools on this computer.
0 = Public.
